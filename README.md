# 一字伝心

`index.html` をEdgeやChromeで開くと遊べます。インストール・アカウント・通信は不要。3〜8人で端末1台を囲み、回答は口頭です。

1. 全員の名前とジャンルを選ぶ。
2. 出題者だけがお題を確認し、漢字ヒントを最大5個準備する。
3. 秘密を隠してみんなに画面を向ける。出題者が好きなタイミングで一字ずつ公開する。
4. 最初に正解を言った人を出題者がタップして採点する。
5. 全員が2回ずつ出題したら、回答点と出題点の合計で順位を表示する。

1〜5文字での正解は、回答者100/80/60/40/20点、出題者50/40/30/20/10点。誤答は次の漢字まで再回答不可。正解なしは0点。同時正解は複数選択でき、出題点は1回分です。結果は次のお題へ進む前なら訂正できます。

やさしい105問（7ジャンル×15問）を収録。単独ジャンルは15問なので、8人では「なんでも」を選んでください。同じゲーム内のお題は重複しません。

途中経過は利用ブラウザーに保存します。「前のゲームの続きから」で再開できます。保存できない場合は案内を表示します。端末間の同期、音声認識、オンラインルーム、公開配信には対応していません。

開発用プレビュー：このフォルダーで `node serve.cjs` → http://127.0.0.1:8781 。終了はCtrl+C。

検証：`node verify.cjs`。このPCのPlaywrightとEdgeを使用します。3人6ラウンド・8人16ラウンド、同時正解、採点訂正、保存復元、秘密表示、画面幅を確認します。

仕様：`../ichiji-denshin-spec.md`。実機のiPad/Safari・Androidと、実際の口頭回答での試遊は別途必要です。
